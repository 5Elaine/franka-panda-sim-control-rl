# Historical PPO v3/v4 comparison script

`train_and_compare_ppo_v4_vs_v3.py` is retained as experiment provenance. It depends on the original `panda_joint2_env_v3.py` and PPO v3 checkpoint, which were not present in the curated project bundle. Use the parent directory's `train_ppo_v4.py` to train the included v4 environment directly.
